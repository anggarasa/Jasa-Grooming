# Memori: scout (konteks proyek)

- **Tanggal Scan**: 2026-10-23
- **Status Proyek**: Existing / Brownfield (Fondasi Phase 01 selesai)
- **Tech Stack**:
  - Framework: Next.js 16.4.2 (App Router), React 19.3.0, TypeScript 5
  - Styling & UI: Tailwind CSS v4, Radix UI, Lucide React, Sonner (Shadcn UI style)
  - Database & ORM: PostgreSQL, Prisma ORM 6.4.1
  - Testing: Vitest 5.0.5, @testing-library/react 16.3.3, jsdom
  - Storage & Auth Utils: MinIO 8.0.7, bcryptjs 3.0.3, Zod 4.6.7
- **Lokasi Kode**:
  - `src/app/`: Next.js App Router pages, layout, route handlers
  - `src/components/`: Reusable UI & presentation components
  - `src/lib/`: Database client (Prisma), storage (MinIO), and utility helpers
  - `src/config/`: Configuration files
  - `prisma/`: Prisma schema, migrations, seed data
  - `tests/`: Unit and integration test suites
- **Konvensi**:
  - ESLint 9 + TypeScript strict mode (`tsc --noEmit`)
  - Testing menggunakan Vitest (`npm run test`)
  - Validasi schema menggunakan Zod
  - Secret & credentials selalu via environment variable (lihat `.env.example`)
- **Catatan untuk Tim**:
  - Sudah memakai Tailwind CSS v4 & Radix UI / Shadcn UI components. Jangan menambahkan UI library lain.
  - Untuk Phase 02 (JWT Auth & Admin Access), manfaatkan Prisma client di `src/lib/` dan `bcryptjs` yang sudah terpasang.
